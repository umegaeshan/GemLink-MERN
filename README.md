# GemLink — Rough Gem Marketplace

A university project connecting rough gemstone sellers in Ratnapura,
Sri Lanka, with interested buyers.

## Planned core features

- Buyer and seller registration and login
- Individual stone and lot listings
- Search and basic filters
- Buyer inquiries with optional offer prices
- Admin listing moderation

## Planned technology stack

- Frontend: React, Vite and Tailwind CSS
- Backend: Node.js and Express
- Database: MongoDB Atlas

## Development stages

1. Build and test the backend with MongoDB Atlas.
2. Build and connect the React frontend.
3. Verify the complete website locally.
4. Add Docker.
5. Deploy manually to AWS.
6. Add CI/CD.

## Current status

Initial repository setup. Application development has not started.

## Authenticity notice

Gem type and details are seller-provided.
Listing approval does not certify authenticity.
